# Data Dictionary

The repository includes the supplied Google stock-price dataset.

The notebook and application inspect the actual CSV columns. Typical financial fields include:

| Column | Description |
|---|---|
| Date | Observation date |
| Open | Opening price |
| High | Highest price |
| Low | Lowest price |
| Close | Closing price |
| Volume | Trading volume |

For this project, `Close` is the preferred forecasting target when available.
